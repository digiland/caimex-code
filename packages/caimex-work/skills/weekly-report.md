# Weekly report

Gather from the folder: `reports/`, `drafts/`, notes and anything dated in the last 7 days.

Structure:

1. **Headline** — the one thing that matters most this week.
2. **Done** — bullets, each with its outcome, not just the activity.
3. **In progress** — status and expected completion.
4. **Risks and blockers** — with what's needed and from whom.
5. **Next week** — the plan, in priority order.
6. **Numbers** — any KPIs with last week's value for comparison.

Keep it under a page. Save to `reports/YYYY-MM-DD-weekly.md`.
