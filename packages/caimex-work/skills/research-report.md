# Writing a research report

Save the report as Markdown in `reports/`, named `reports/YYYY-MM-DD-<short-topic>.md`.

## Structure

1. **Title** and a one-line scope ("What this covers, as of <date>").
2. **Summary** — 3 to 6 bullets a busy reader can act on. Lead with the answer, not the method.
3. **Findings** — sections by theme, not by source. Each claim that isn't common knowledge carries a citation.
4. **Numbers** — put figures in a table with units, date and source per row.
5. **Open questions and caveats** — what you couldn't verify, conflicting sources, stale data.
6. **Sources** — numbered list: `[n] Title — Publisher, date. URL`.

## Citations

- Cite inline as `[n]` matching the Sources list.
- Prefer primary sources (company filings, regulators, official statistics, the original study) over coverage of them.
- Every number needs a date. Say "as of" when the figure could have changed.
- Never invent a URL, figure or quote. If you only saw something in a search snippet and couldn't open the page, say so.

## Length

- A brief: one page (about 400–600 words).
- A report: as long as the question needs, but put detail in appendices, not the summary.
